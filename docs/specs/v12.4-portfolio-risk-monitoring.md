# V12.4 — Portfolio Risk Monitoring

## Scope
Deterministic, paper-only portfolio risk observation for concentration, gross exposure, and drawdown.

## Rules
- Risk monitoring is advisory/observational and never submits orders.
- Position concentration is evaluated only when `PortfolioRisk:MaxPositionWeight` is configured.
- Gross exposure is evaluated only when `PortfolioRisk:MaxGrossExposureRatio` is configured.
- Drawdown is evaluated only when `PortfolioRisk:MaxDrawdownPercent` is configured and a positive peak-equity value is available.
- Unset thresholds do not invent a risk policy; invalid configured thresholds are rejected.
- Missing market prices fall back to average entry price.
- Threshold validation occurs before evaluation.

## Implementation boundary
- The canonical evaluator is `AiTrading.Application.PortfolioRiskMonitor`.
- Durable monitoring invokes the evaluator after refreshing the current paper portfolio prices and persists only deduplicated advisory alerts.
- The evaluator and monitor do not submit, cancel, modify, or liquidate orders.

## Acceptance
A paper portfolio can be evaluated deterministically and produces typed severity events for configured threshold breaches. Unit tests cover concentration, gross exposure, drawdown, price fallback, missing peak equity, and invalid configuration.
