# V12.3 News Monitoring Integration

## Scope

This slice connects the provider-independent news contract to the existing advisory alert boundary. It does not select a production news vendor and does not authorize trading.

## Behavior

- `IMarketNewsProvider` is the provider boundary.
- Provider failures return a structured monitoring result and do not create alerts.
- Existing deterministic recency/materiality classification remains authoritative.
- Current medium/high-materiality news affecting at least one symbol becomes an advisory alert candidate.
- Alert candidates are deduplicated by stable news item id within a monitoring pass.
- News alerts never create, modify, or close orders.

## Acceptance

- Provider success and failure are covered by tests.
- Stale and otherwise non-actionable items produce no alert.
- Actionable items produce severity based on materiality.
- Duplicate provider results produce one alert candidate.
- No external notification channel or broker integration is introduced.
